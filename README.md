# TachyonBeing Skills

Sovereign AI Agent skills for Polymarket trading, crypto operations, and real-time intelligence.

## Skills

- **osint-polymarket-edge** - Real-time OSINT data feeds for Polymarket trading edge
- **crypto-wallet-defi** - Multi-wallet management and DeFi protocol integration
- **cyber-threat-monitor** - Real-time cyber threat intelligence monitoring

## Setup

Clone this repo and place skills in your Hermes Agent skills directory:

```bash
git clone https://github.com/TachyonBeing/tachyonbeing-skills.git
cp -r tachyonbeing-skills/* ~/.hermes/skills/
```
